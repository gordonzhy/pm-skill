# Claude Code 适配

复用 PM Skill 核心规则和确定性工具，不假定 Codex 工具名称、会话 API、Hook 文件位置或信任方式在 Claude Code 可用。

按实际宿主版本的 Skill 发现机制安装本目录。当前候选未完成真实加载、独立会话、恢复、回调和独立验收能力验证；需要这些能力时先核实环境，缺少时按规则说明缺口，不声称已经派发或验收。

观察可通过 PM Server 的标准事件入口对接。原生 Hook 自动安装尚未实现，不能把示例 ingest 成功当成 Claude Code 生命周期接入成功。完整会话引用使用 `claude-code:<实例>:<原生ID>`，各部分按契约编码。
