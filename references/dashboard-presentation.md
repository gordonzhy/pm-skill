# 看板呈现契约

仅在页面设计、交互、生成或前端验收时读取。本文区分**统一工作台**与**兼容项目内视图**，禁止把后者的旧筛选、分组或颜色套到工作台。任务状态及验收仍按 [任务系统](task-system.md)，连接管理按 [工作台](workbench.md)。

## 共同原则

深色界面优先信息层级、状态辨识、文字对比和窄屏可读性，装饰置后。任务索引负责事实与生命周期，页面只读呈现。筛选、排序、缩放、显示列等浏览器偏好不成为项目事实，不修改 CSV。

图标统一从 `project-manager-logo.svg` 派生：深色圆角底板、青蓝几何 M；页面、Skill 图标与 favicon 保持同源，小尺寸清楚，SVG favicon 配 PNG 备选。

悬停/聚焦节点提供视口内可滚动预览；直接点击节点或按Enter/空格打开任务详情弹窗，预览中的详情按钮仍可使用。Escape关闭预览或当前详情；元数据来自 CSV，Markdown 惰性读取并安全渲染，只允许安全链接。完整详情在页面弹窗显示。连线仅在项目内且两端匹配当前图规则时绘制，ID/标题/依赖来自真源。

只关联已登记会话观察；缺失 `unknown`、过期 `stale`，不可伪装 `running`。状态持续时间取状态开始时刻，新鲜度取最近观察时刻。SSE 只提示重读，初连/重连取新快照；无数据轮询或常驻刷新按钮。相对时间本地每秒更新、切回页面校正，不发数据请求。显示刷新和项目恢复监测独立，均不等于验收。

## 统一工作台：信息与操作

页面按“项目范围 → 状态统计 → 视图与工具栏 → 单一内容面”排列。项目快捷按钮常驻、多选/全选，勾选、高亮及 `aria-pressed` 同时表达状态，偏好跨刷新保留。项目不做独立 Tab，图链以项目标题与细线区分。

“任务依赖图”“任务列表”两个 Tab 共用搜索、状态、类型/优先级及列条件，切换不清空。默认聚焦未终结任务，可查全部/已终结。顶部顺序以待确认、进行中开头，并含可开始、等待依赖、受阻、未终结；点击即筛选。统计基于选中项目全量，内容数基于筛选结果，口径标明。类型/优先级在筛选弹层，已生效条件可见并可清除。

- **图：** 完整展示所有筛选结果，不受列表分页截断；高度随内容向下展开，无内部纵向滚动，仅横向溢出。筛掉的前置节点不画线，显示筛选外依赖数；不以其他项目同 ID 补线。支持10%–200%、100%复位、适应宽度、折叠，偏好持久化。预览及当前页表格高亮关联节点与线。
- **列表：** 一张大表，不按状态、项目或类型分组；设置可选全部实际 CSV 字段及计算态势。各显示字段均可排序/筛选；分类精确选择，文本/路由/依赖包含过滤，日期支持 ISO 与显示的本地时刻。ID/优先级自然排序、日期按真实时刻；所有条件 AND，在全集过滤排序后按50项分页。
- **列过滤：** 列旁图标打开弹层，不常驻第二行输入；条件跨 Tab 可见。重绘保留输入焦点、光标与弹层，Escape/点击外部关闭。窄屏标题、状态列靠前，标题下补编号/来源，完整字段仍可横向查看并独立排序筛选，不篡改显示列偏好。

## 统一工作台：视觉

午夜靛蓝背景 `#10162A`、钢蓝内容面 `#19243B`、冰青品牌 `#67D8EF`、柔紫辅助 `#A99AF7`。项目筛选不套外框；统计为分段柔和色面，不堆独立渐变卡片。表格轻交替底色与弱分隔，内容紧凑但不继续缩小正文。

| 态势/状态 | 基调 |
| --- | --- |
| 待确认 | 紫 |
| 进行中 | 蓝 |
| 可开始 | 绿 |
| 等待依赖 | 灰 |
| 受阻 | 红 |
| 已完成 | 绿 |
| 已取消 | 灰 |

可开始/等待依赖是正式 `待办` 的计算姿态，图例可独立筛选。正式状态文字保留待办，补充姿态文字和相应色；不能据此直接派发。图例、汇总、节点、预览、表格边线/徽标及依赖标记一致。类型次级中性，项目用稳定浏览器色点加名称；项目色不取代状态，项目多时允许色点重复。P0 独立金色强调，不改变任务状态或派发顺序。

节点约246×104，图项目标题14px、任务标题13px、编号/类型11px。节点底色比画布浅，柔和状态底色配状态边条；受阻/待确认适度加强。**状态标签仍居卡片右上角，仅标签内部文字水平和垂直居中。** 长 ID 截断后可从完整提示/预览读。项目底面随可用宽度、缩放及 Tab 显示变化调整，不为填空白拉长连线。悬停/聚焦突出关联线，尊重减少动态效果设置。

标题/图标单行，收紧项目条和统计留白，视图切换、通用筛选和图操作共用工具栏。窄屏重新排布工具栏，项目按钮及表格仅在自身横向滚动，按钮条边缘渐隐提示溢出，真实连接状态保持可见。

## 统一工作台：设置与来源选择

设置弹窗左侧垂直菜单、右侧独立滚动，五项为项目管理、添加项目、注册申请、显示字段、最近移除；窄屏保留收窄左栏，标题与关闭固定。一次一个面板，可访问 Tab 语义，上下键/Home/End 导航，切换保留未提交草稿；不恢复折叠菜单或主页面移除控件。

项目卡显示名称、组与 CSV 路径；添加支持直接路径和本机文件浏览弹窗，快捷位置、上级、路径输入、列表筛选与隐藏项。目录异步加载不覆盖正在输入的路径，检查结果不覆盖已变更的来源。选择/检查只展示根目录与任务数，用户点击添加才登记。最近移除提供重新添加和实际删除记录，行为及隐私边界见工作台。

## 兼容项目内视图（不是工作台）

`assets/task-dashboard.html` 生成各仓库 `TASKS.html`。继续保留旧六状态/类型配色及原布局，顶部先待确认、进行中，状态下拉默认“全部进行中”（全部未终结），可选全部/终结状态。其类型筛选可保留并淡化非匹配依赖上下文；工作台则剔除不匹配节点及边，两者不可混写。

项目内通知只在用户主动授予权限后，对新进入待确认每次提醒一次，本地去重。以 HTTPS 或本机 HTTP（`127.0.0.1` / `localhost`）打开；`file://` 显示改用工作台项目内链接的指引，不提供权限按钮。未授权显示站点设置指引，授权且无发送错误时隐藏整条提示，不常驻测试按钮；同步或异步发送失败须显示原因并保留重试机会。权限按浏览器站点分别保存，授权不会发送独立测试通知；页面须保持打开，系统通知设置也会影响桌面显示。测试详情按 suite/问题清单显示开放与阻断数及链接，读取失败显示不可用；只开放显式证据路径。

修改模板后生成并执行 `node <Skill>/scripts/validate-dashboard-presentation.mjs --repo <仓库>`，此检查只针对项目内生成 HTML。工作台前端使用 `workbench-browser-test.mjs` 实际浏览器回归及对应模块测试，不能用旧 HTML 呈现检查冒充工作台验收。模板生成不自动重启产品或服务；服务实现变更按已有归属核对恢复。

## 任务详情时间轴

统一工作台与项目内视图共用详情弹窗，设置“任务说明 / 任务日志”两个可键盘操作的Tab；不改变主页面图/表Tab。新任务默认打开说明，实时刷新同一任务保留当前Tab。日志按 [结构化日志](task-log.md) 解析，按真实时刻倒序，默认显示短摘要，完整正文/影响/依据/路由按条展开；同批未知发生时间的历史补记分组收起，原文保留，失败和实际状态变化仍可见；未知发生时间不伪造。描述不重复YAML代码，日志长时内容区独立滚动，窄屏无横向溢出。

从统一工作台打开单个任务时，只显示一层详情弹窗及一个关闭按钮，不把完整项目看板作为可见背景嵌进另一层。复用项目模板时用专用详情嵌入模式：宿主拥有唯一模态，嵌入内容仅展示任务说明/日志且不再调用showModal；关闭与Escape通过同源、来源窗口验证通知宿主，读取失败在详情区域可见。点击来源项目则在独立页面打开完整项目看板。

任务日志后台刷新须保留展开状态、滚动位置与键盘焦点；未变化的 Markdown 不重建详情 DOM，切换任务时重置。

统一工作台顶部的项目“全选”按钮是切换按钮：全部选中时显示“全不选”，点击清空；部分或未选时显示“全选”，点击选中全部。空选择持久保存，清空后点击一个项目即可单独查看。

统一工作台顶部固定“通知”入口，设置左侧保留“通知提醒”，显示权限、暂停/开启、测试通知及当前待确认任务和注册申请。通知覆盖全部已连接项目，不受显示筛选影响；复用项目内待确认去重键，详情 iframe 不重复发送。读取失败不当成离开待确认；同步/异步投递失败撤销去重并保留重试机会。测试通知只确认浏览器接收创建请求，不能据此声称系统桌面已展示。页面需保持打开，操作系统通知/勿扰设置独立影响展示。

依赖图提供右下角可收起的缩略地图，按当前筛选绘制全部任务的简化状态色块和依赖，不受列表分页截断。视野框同步主图缩放、页面纵向滚动、图区域横向滚动及窗口尺寸；点击/拖动地图定位对应位置，方向键移动视野，Home/End 跳至首尾。列表 Tab、主图收起、空筛选或主图离开视口时隐藏；窄屏缩小，不引入内部纵向滚动。收起偏好仅存浏览器。缩略图不复制可交互任务卡或触发任务详情请求。


依赖图卡片显示“执行”累计时长，详情弹窗在说明/日志Tab上方显示按绝对时间绘制的SVG活动时间轴：横轴为真实日期与时分秒，区段位置及长度对应实际起止与持续时间，事件时点用菱形标记；不使用相对00:00起点或表格替代。活动来自日志显式`started_at`/`ended_at`，所有活动共用一行彩色时间带，图高固定约64px，不随事件数增长；不同活动使用不同颜色，未记录区段虚线，事件节点叠在同一时间带。鼠标悬停、键盘聚焦或触摸区段时浮出完整日期时间和具体工作，默认不占用常驻详情高度；悬停/聚焦期间本地刷新不打断阅读。跨日刻度带日期，页面标明本地时区，窄屏图形内部横向滚动。没有活动起止数据时只显示事件时点且标明未记录持续时间；区间缺口明确标注，并行活动分别展示。统一使用结构化日志中带真实发生时间的 `state_to` 划分状态区间，`paused` 明确暂停区间；`进行中`累计为总执行时间（状态耗时，不是人员工时）。`state_from`不连续或最新日志与CSV状态冲突的区间归为未知；`supersedes`排除被更正事件，重开继续累计，当前终结状态与日志一致后停止计时。缺少日志、读取失败、日志错误或没有有效状态边界时显示无法统计，不能显示为零；历史缺口、未知时间或未结构化历史显示已记录及不完整原因，不用补记时间或更新时间替代实际发生时间。已打开页面每秒本地更新，不因计时发起请求。

任务卡悬停/聚焦预览浮层也复用同一条单行彩色活动时间轴，适配浮层宽度并减少刻度数量。读取已缓存的任务Markdown计算，不额外发请求；详情读取失败时显示不可用，不沿用其他任务的时间条。悬停色块或键盘聚焦显示绝对时间及工作内容，切换任务重置。
